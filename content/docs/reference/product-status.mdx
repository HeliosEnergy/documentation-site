This page is the single list of Helios products and their status. Live products are available in the console now. Other products are arranged with the Helios team or cannot be requested in the console yet.

## What is available?

| Product | Status | What it means |
|---|---|---|
| [Bare metal (B300)](/docs/bare-metal) | <Status state="live" /> | Request access to a node with 8 NVIDIA B300 GPUs with an SSH public key. Helios approves the request and installs your key. An organization Admin or Owner starts access, and you connect over SSH. Bare metal usage is recorded by the hour, pro-rated to elapsed time, starting at **Start access**. |
| [Jupyter notebooks (RTX PRO 6000)](/docs/notebooks) | Allocation unavailable | A workspace admin allocates a JupyterLab node. Notebook allocation is currently unavailable in the console, which shows RTX PRO 6000 notebooks as At Capacity. Contact the Helios team for access. |
| [AI inference](/docs/inference) | <Status state="live" /> | Model marketplace, playground, request history, per-model telemetry and monthly budget alerts. |
| [API and API keys](/docs/api) | <Status state="live" /> | Inference endpoints and bare metal endpoints, authenticated with API keys. |
| [Wallet and billing](/docs/billing) | <Status state="live" /> | Prepaid wallet for each workspace, card top-ups and a transactions list. |
| [Users and access](/docs/accounts/users-and-access) | <Status state="live" /> | Organizations, workspaces, invitations, guests, and the Owner, Admin and Member roles. |
| [Reserved GPU clusters](/docs/bare-metal/reserved-clusters) | Arranged with the Helios team | Contracted capacity that you arrange with the Helios team. It is not requested in the console. |
| GB300 NVL72 | Contact the Helios team | Not yet available in the console. Contact the Helios team for details. |
| RTX PRO 6000 bare metal | Contact the Helios team | Not yet available in the console. Contact the Helios team for details. |

Helios does not currently offer containers or deployments, scheduled jobs, a command-line tool or an SDK. You can call the API from any HTTP client with your API key.

## Where can I find pricing and contract options?

Pricing is on [helios.co/pricing](https://www.helios.co/pricing). To discuss reserved capacity or products that are not yet available in the console, [contact Helios](https://www.helios.co/contact).
