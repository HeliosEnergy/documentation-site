title: Reserved clusters
description: Committed, reserved GPU capacity is arranged with the Helios team. It is not requested in the console and is not available on demand.

Reserved clusters are committed GPU capacity that you arrange with the Helios team, not capacity you request in the console. This is different from the on-demand B300 access described in the rest of this section.

Reserved cluster capacity is arranged by contract and is not requested or allocated in the console. These docs do not publish specifications or availability for reserved clusters. To ask about capacity, [talk to the Helios team](https://www.helios.co/contact).

## How is it different from on-demand bare metal?

| | On-demand B300 access | Reserved cluster |
|---|---|---|
| How you get it | Request in the console, approval required | Arranged with the Helios team |
| Commitment | Time-limited access window | Committed, reserved capacity |
| Billing | Recorded by the hour, pro-rated to elapsed time, starting at **Start access**. See [Billing and access windows](/docs/bare-metal/billing-and-access-windows) | By contract |

The **Reserved** view on the console **Baremetal** page is for reference only. You cannot request capacity from it.

## How do you ask for reserved capacity?

1. Read the overview at [helios.co/clusters](https://www.helios.co/clusters).
2. Check the published pricing at [helios.co/pricing](https://www.helios.co/pricing).
3. Send your requirements through [helios.co/contact](https://www.helios.co/contact): GPU platform, number of GPUs or nodes, term, and when you need to start.

## What about RTX PRO 6000 bare metal and GB300 NVL72?

Both appear in the console as **Contact us**. They are not yet available in the console, and you cannot request them there. [Talk to the Helios team](https://www.helios.co/contact) about availability.
