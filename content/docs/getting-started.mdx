## Introduction

Helios <span className='text-fd-muted-foreground text-sm'>(Heel-ee-os)</span> is a cloud platform designed to give developers and businesses instant, scalable access to GPU resources for AI inference. We handle the infrastructure so you can focus on deploying and scaling your models.

Helios has different parts:

<Cards>

<Card icon={<Cpu className="text-orange-400" />} title='GPU Access'>

Handles the core GPU infrastructure, providing instant access to high-performance computing resources for AI workloads.

</Card>

<Card icon={<Server className="text-orange-400" />} title='Deployment Platform'>

The deployment system that manages containerized applications, handles scaling, and ensures reliable GPU resource allocation.

</Card>

<Card icon={<FolderOpen className="text-orange-400" />} title='Workspaces'>

Organize your projects, manage teams, and control access to GPU resources across different environments.

</Card>

<Card icon={<Shield className="text-orange-400" />} title='Security'>

Built-in security features to protect your AI models, data, and GPU resources with enterprise-grade protection.

</Card>

</Cards>

### Prerequisites

<Callout type="warn" title="What you need to get started">
  - A Helios account ([Sign up here](#)).
  - A Docker Hub account (or other container registry).
  - Basic familiarity with Docker.
</Callout>

### Your First Deployment

    #### 3. Deploy a Model
