The Helios console has a left sidebar for products, a workspace switcher at the top and a user menu at the bottom. This page describes each part and where to go for more detail.

## What is in the sidebar?

| Sidebar item | What it does | Guide |
|---|---|---|
| **Overview** | Summarizes your workspace, including active resources and featured AI inference models. | This page |
| **Baremetal** | Request access to a B300 node, start access, connect over SSH and view GPU telemetry. | [Bare metal](/docs/bare-metal) |
| **AI Inference** | Browse the model marketplace, use the playground, review request history, see per-model usage and manage API keys. | [AI inference](/docs/inference) |
| **Jupyter Notebooks** | Shows the RTX PRO 6000 JupyterLab card. Notebook allocation is currently unavailable in the console, which shows RTX PRO 6000 notebooks as At Capacity. Contact the Helios team for access. | [Jupyter notebooks](/docs/notebooks) |
| **Wallet** | View your balance and transactions and add funds. | [Billing and wallet](/docs/billing) |
| **Documentation** | A link to the Helios documentation. | [Documentation home](/docs) |

Check [Product status](/docs/reference/product-status) for the full list of what is available.

## How do I switch workspaces?

The workspace switcher sits at the top of the sidebar. It shows the name of your current workspace and, underneath, the organization that owns it. Select it to see every workspace you can access and choose another one. A green dot marks the current workspace.

Workspaces you were invited into from another organization show that organization's name under the workspace name. Each workspace has its own wallet, so check which workspace is selected before you add funds or start work. See [Organizations and workspaces](/docs/accounts/organizations-and-workspaces).

At the bottom of the switcher, **Create workspace** opens a dialog where you enter a name and select **Create**. Creating a workspace requires the Owner role.

## What is in the user menu?

Select your name at the bottom of the sidebar to open the user menu.

- **Users & Access** shows organization members, workspace access and invitations. The item does not appear if you are a guest in another organization's workspace. See [Users and access](/docs/accounts/users-and-access).
- **Logout** ends your session.

## Where do I find API keys?

You create and manage API keys from the AI Inference section of the console. See [Authentication and keys](/docs/api/authentication-and-keys).
